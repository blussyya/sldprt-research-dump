# EXP-071 — Typed export records, topology, and node IDs

First produced 2026-09-28; publication checkpoint 2026-09-29 UTC. Base: staging `0df1dadfbaa1daec390c9351eb3b82f7aea8ad4f`.

Run `node knowledge/evidence/scripts/EXP071/audit.js --write` from the repository root. [Reader](scripts/EXP071/typed-reader.js), [audit](scripts/EXP071/audit.js), and [raw results with all input hashes](scripts/EXP071/RESULTS.json) preserve the method and observations. The source is the repository's controlled corpus and the owner-authored [October 2006 XT reference](https://www.13thmonkey.org/documentation/CAD/Parasolid-XT-format-reference.pdf), especially printed pages 3–17, 28–79, 85–107. Technical field layouts are implemented as code; the reference text is not reproduced.

## Results

All 49 X_T / X_B pairs parse contiguously through their terminators: 7,000 typed records in each format, 98 complete exports. The binary transmit bytes after the ASCII banner are partitioned into labelled ranges without gaps or overlaps. This is structural coverage of these payloads, not proof of every field's semantic meaning.

28,428 graph checks pass. These check face/loop ownership, reciprocal forward/backward fins, two-fin edge rings, opposite edge senses, referenced points, and spline control/knot array sizes and knot order. Native face counts from the build log agree in all exports. The tested corpus is manifold; this does not establish arbitrary non-manifold support or spline evaluation correctness.

The C00 cubes also pass: six faces, twelve edges, eight vertices, four fins per face loop, Euler characteristic 2, plane incidence, outward loop orientation, bounds `[0,.01]` m per axis, and volume `1e-6` m³. These checks walk decoded topology and exact point/plane records rather than display triangles.

## ID result and cross-format differences

94/98 exports have `highest_node_id == max(decoded node_id)`. Both eras' loft exports, in both formats, have a **gap of 16**. Every decoded positive ID is unique and at or below the stored ceiling. Exact surviving-maximum equality is therefore falsified for the corpus. This does not prove an allocation-history explanation.

Across the paired exports, the only non-floating field differences are 24 BODY ceiling values and 308 ATTRIBUTE node IDs. No decoded FACE node ID differs. Thus the older suggestion of face re-tagging is not supported by the actual entity comparison. Floating values compare with the script's stated tolerance; the maximum absolute difference is `1.1368683772161603e-13`, arising from the binary size value near 1000.

## Schema qualifications

- The BODY field table includes `nom_geom_state`; the nearby C struct omits it. The table supplies the 23-field base layout corroborated by the embedded edits and record boundaries.
- The EDGE table has one attribute pointer; its C struct repeats it. The table reading is used.
- The ELLIPSE C struct omits the common geometry sense. The common geometry layout and successful typed boundaries corroborate its presence.
- LIST's nine effective base fields are a **candidate reconstruction** from the embedded edit script and observed values. The later twelve-field reference struct is not treated as the base schema. Full topology traversal and EOF checks corroborate this reconstruction, but an independent `sch_13006` file has not been obtained.
- Embedded field `n_elts` is decoded separately from logical transmit status. A full new-type declaration is accepted only when its name, description, and typed descriptors parse in place. Missing base layouts fail explicitly.

## Controls and byte maps

The audit rejects a corrupt fin target through topology checks; it also detects a truncated terminator, trailing byte, malformed numeric token, and a ten-node limit. Synthetic pointer tests exercise the short/long encoding boundary, including a legitimate encoded word equal to the integral null sentinel; pointer words must not pass through scalar null conversion.

Full C00 maps include offsets, field kinds, values, schema edits, node indices, graph references, and raw hex: [SW2011](scripts/EXP071/C00_SW2011_XB_MAP.json.gz), [SW2022](scripts/EXP071/C00_SW2022_XB_MAP.json.gz). They are gzip-compressed JSON, reproducibly regenerated by the command above. X_B offsets are absolute file byte offsets; text positions are normalized stream positions after removing CR/LF. The ASCII banner is retained as an explicitly separate region, not exhaustively interpreted here.

No converter, spline evaluator, native delta replay, or production parser change is claimed by this experiment.
